# Fonts Directory

This directory should contain the custom web font files referenced in lake_styles.css:

## Required Font Files:

### Cinzel (for headings):
- Cinzel-Regular.woff
- Cinzel-Regular.ttf

### Lato (for body text):
- Lato-Regular.woff
- Lato-Regular.ttf

## Where to get fonts:

These fonts can be downloaded from:
- **Google Fonts**: https://fonts.google.com/
- **Font Squirrel**: https://www.fontsquirrel.com/

## Note:

These font files would typically be provided as part of the assignment ZIP archive. If not available, the page will fall back to:
- Georgia (for headings)
- Arial (for body text)

The page will still function properly without the custom fonts, but the typography won't match the intended design exactly.
