# Images Directory

This directory should contain the following image files:

1. **banner.jpg** - Lodge banner image displayed at the top of the page
2. **staff.jpg** - Staff photo displayed in the welcome section

These images would typically be provided as part of the assignment materials.

For testing purposes, you can use placeholder images or any appropriate images of:
- A scenic lodge/lake banner (approximately 1200x300px)
- Lodge staff or a welcoming photo (approximately 400x300px)
